Infera

A Prolog-inspired logic programming language with declared or inferred sorts, modes and determinism, indexing and tabling on by default, cut and if-then-else, a simple CLP(Z) solver, DCGs and a hash-addressed module system. Implemented in Haskell.

# Clauses use <- ; queries end with ? ; > lines run when the file loads.
fact : det (int: <=) (int: =>).
fact 0 1.
fact N R <- N > 0, N1 is N - 1, fact N1 R1, R is N * R1.

path X Y <- path X Z, edge Z Y.     # left recursion is fine: tabled by default
path X Y <- edge X Y.

puzzle X Y <- [X, Y] in 0..20, X + Y #= 10, X - Y #= 2, label [X, Y].

> fact 20 R?
R = 2432902008176640000
> puzzle X Y?
X = 6, Y = 4

Sorts, modes, determinism

name : semidet (int: <=) (str: =>). Declared signatures are enforced; undeclared predicates are analysed and the sound part of the analysis is used to drop choice points.

Indexing and tabling

Every argument is indexed. Recursive, pure predicates are tabled automatically, so left recursion terminates and fib is linear.

CLP(Z)

Interval domains, bounds propagation, #= #!= #<…, all_different and label. SEND + MORE = MONEY in a quarter of a second.

Tooling

REPL with :sig, infera check, a VS Code extension with a language server, and Homebrew installation.
