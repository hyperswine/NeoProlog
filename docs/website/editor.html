Editor support

The repository ships a VS Code extension with a language server for .nprolog and .infera files.

Install the extension #

cd lsp
npm install
npm run install-extension     # packages infera-lsp.vsix and installs it into VS Code

Or run npm run package and install the .vsix through Extensions → … → Install from VSIX.

Features #

  • Highlighting: a TextMate grammar plus semantic tokens for clause heads, declarations, sorts, modes, module namespaces and inline queries.
  • Hover: built-in documentation, predicate clause counts and declared signatures, declaration keywords, imported modules.
  • Navigation: go to definition, find references and document symbols (name/arity), including mod:pred calls resolved through neoprolog.conf.
  • Completion: local predicates, module aliases (mod: completes the module's predicates), built-ins, and determinism words, flags, sorts and modes inside a declaration.
  • Diagnostics from static analysis: undefined predicates, calls with an arity no clause defines, declarations without clauses or with the wrong arity, malformed declarations, unknown directives, unbalanced brackets, missing terminators and singleton variables.
  • Parser diagnostics: when the infera binary is available, infera check runs on open and save and its errors are shown at the reported position.

infera.executableinferabinary used for infera check

Other editors #

The server in lsp/server/server.js speaks standard LSP over stdio-less IPC as launched by the VS Code client; any editor that can launch a Node language server can use it by running node lsp/server/server.js --stdio after switching the connection to stdio, and the analyser in lsp/server/analysis.js is a plain module usable from other tooling.
