Declarations

A declaration states a predicate's determinism, the sort and mode of each argument, and per-predicate flags. Declared signatures are enforced at runtime; undeclared predicates are analysed.

Syntax #

mypred : semidet (int: <=) (int: <=>) (str: =>).
len    : det (list any: <=) (int: =>).
plus2  : det <= =>.            # bare modes: sort any
nat    : notable.              # flags only: applies to every arity of nat
PartValues
Determinismdet exactly one solution · semidet at most one · multi at least one · nondet any number (default)
Sortint float num str char atom any, list <sort> (nest with parentheses: list (list int))
Mode<= input: ground at call · => output: ground after the call · <=> no requirement (default)
Flagstable notable index noindex

A bare sort in parentheses means <=>: (int) is (int: <=>). A declaration with only flags and no argument specs applies to every arity of the name. Several declarations of the same predicate are alternative modes; the first one whose input arguments are ground in the call is used.

Keywords #

WordMeaning
detExactly one solution. Failing is a determinism error; the first solution is committed to.
semidetAt most one solution; the first solution is committed to.
multiAt least one solution; failing is a determinism error.
nondetAny number of solutions.
table / notableForce tabling on or off for the predicate (see tabling).
index / noindexForce argument indexing on or off.
int, float, numIntegers, floats, either.
str, char, atomStrings, characters, atoms.
list S, anyProper lists of sort S; anything.
<=, =>, <=>Input, output, in/out mode.

What is enforced #

  • An input argument that is not ground at the call: mode error.
  • An argument whose bound part does not match its sort, before or after the call: sort error. Output arguments must be ground after the call.
  • det and multi predicates that fail: determinism error.
  • det and semidet predicates commit to their first solution, so remaining choice points are dropped.
fact : det (int: <=) (int: =>).
fact 0 1.
fact N R <- N > 0, N1 is N - 1, fact N1 R1, R is N * R1.

> fact X 5?
Error: mode error: argument 1 of fact/2 is declared input (<=) but is not ground: X
> fact a R?
Error: sort error: argument 1 of fact/2 must be int, but got: a

Inference #

Undeclared predicates get the most general signature, nondet with every argument (any: <=>), unless the analysis can do better. The REPL command :sig name shows the result:

> :sig length
length/2
  inferred: length : semidet (list any: <=>) (num: =>).   # semidet when argument(s) 1 ground
  clauses: 2, tabled: no, indexed: yes, recursive: yes, pure: yes
  • Sorts come from head patterns, literals, arithmetic, string built-ins and the sorts of called predicates, iterated to a fixpoint. int and float evidence join to num; conflicting evidence gives any.
  • Modes: <= when some clause needs the argument ground before anything could bind it (a comparison, arithmetic, or an input of a callee); => when every clause leaves the argument ground.
  • Determinism: semidet when the clauses are pairwise exclusive and every body has at most one solution. Clauses are exclusive when they have different principal functors at some argument, complementary guards as their first goal (A >= B against B > A), a literal against a guard that excludes it (0 against N > 0), or a cut. The exclusivity may require some arguments to be ground; those positions are recorded and checked at call time.
Inferred signatures are advisory and never raise errors. The engine uses an inferred semidet only to drop choice points, and only when the recorded argument positions are ground in the actual call. Everything else falls back to full backtracking, so inference cannot lose solutions.
