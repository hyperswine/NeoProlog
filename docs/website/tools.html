REPL, CLI and modules

The infera executable is a REPL, a file loader, a checker and the module registry tool.

Command line #

CommandMeaning
infera FILEload a file, run its inline > queries, then start the REPL
infera check FILE…parse, resolve imports and analyse each file; prints ok (N clauses, M queries) or the error; exit status 1 on failure
infera reg FILE…register files as modules in ./neoprolog.conf

Colours are used only when standard output is a terminal and NO_COLOR is unset, so the output is safe to pipe.

REPL #

Type a clause or declaration ending with . to add it, or goals ending with ? to query. Programs are re-analysed after every addition.

CommandMeaning
:load FILEload a file (replaces the program) and run its inline queries
:reload, :rreload the last file
:sig [NAME]declared and inferred signatures, clause count, tabled/indexed/recursive/pure status
:predslist predicates as name/arity
:quit, :q, Ctrl-Dexit
> :sig fib
fib/2
  inferred: fib : semidet (num: <=) (num: =>).   # semidet when argument(s) 1 ground
  clauses: 3, tabled: yes, indexed: yes, recursive: yes, pure: yes

Modules #

Modules are files registered under a content-addressed name: infera reg path/to/mymod.nprolog appends mymod#<sha1 of the absolute path> /abs/path/mymod.nprolog to neoprolog.conf in the current directory. Infera looks for neoprolog.conf or infera.conf in the working directory, then in ~/nprolog/.

<- import "mymod#3f2a9c...".

main <- mymod:greet "world".
  • Imported clauses and declarations are prefixed with the module name: mymod:greet. Calls inside the module to its own predicates are qualified too.
  • A module's own imports are resolved recursively; cycles are ignored.
  • Inline queries in a module are not run when it is imported.

Answers #

Each answer lists the bindings of the query's named variables, then residual constraints: domains (X in 1..3), CLP(Z) relations (X + Y #= 10) and disequalities (X != 1) that reach a visible variable. Internal variables are named _0, _1, … and a query variable bound to an otherwise anonymous variable lends it its name. Output produced by a branch is printed before that branch's answer.
