Install

Infera is a single executable, infera. Install it with Homebrew on macOS or build it from source with cabal anywhere GHC runs.

Homebrew (macOS) #

brew tap hyperswine/neoprolog https://github.com/hyperswine/NeoProlog
brew install infera

The formula builds from source with Homebrew's GHC (about a minute) and installs the binary, the README and the examples under $(brew --prefix)/share/infera.

From source with cabal #

You need GHC 9.8 or newer and cabal-install, for example via ghcup.

git clone https://github.com/hyperswine/NeoProlog
cd NeoProlog
cabal build
cabal test
cabal install        # puts `infera` into ~/.cabal/bin or ~/.local/bin
If linking fails on macOS with tapi error: malformed file … unknown architecture, your Command Line Tools SDK is newer than the linker Xcode selects. Build with DEVELOPER_DIR=/Library/Developer/CommandLineTools cabal build.

Check it works #

infera examples/stdlib.nprolog     # loads the file, runs its inline queries, opens the REPL
infera check examples/*.nprolog    # parse and analyse without running
