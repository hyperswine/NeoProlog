Built-ins

Predicates provided by the engine. Built-ins take precedence over user predicates of the same name and arity.

GoalMeaning

Effects (unsafe) #

These builtins perform effects and may only appear in inline queries or in predicates declared unsafe; anywhere else the program is rejected at load time with an unsafe-call error. Cut (!) is treated the same way.

GoalMeaning
emit NTrun the DCG NT once and print the text it describes
read_file "path" SS is the file's contents; the path must be a string literal (files are read when the program loads)
phrase_from_file NT "path"parse the file with the DCG NT
assert Factadd a fact of a dynamic predicate; undone on backtracking
retract Fact, retractall Patternremove a matching dynamic fact; remove every matching fact

DCG helpers #

Pure non-terminals for describing text. Together with string literals they make a DCG a complete description of its output; phrase parses with the same grammars (a string argument is read as characters).

Non-terminalDescribes
seq Xsthe elements of a list or string in sequence; with Xs unknown, enumerates prefixes
wr Termthe text of a term (strings without quotes)
nl, spa newline; a space
fmt "…" Argsformatted text: ~w term, ~d integer, ~s string, ~a atom, ~n newline, ~~ tilde
padl Term W, padr Term Wthe text of Term right- or left-aligned in W columns

Related plain builtins: term_str Term S, str_lines S Lines, char_code C N; the comparison operators order characters, strings and atoms as well as numbers.
