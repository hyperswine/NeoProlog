Built-ins

Predicates provided by the engine. Built-ins take precedence over user predicates of the same name and arity.

Control #

GoalMeaning
true, fail, falsesucceed; fail
!cut
not Gnegation as failure
once Gfirst solution of G only
forall C Asucceeds if A holds for every solution of C
findall T G LL is the list of T for every solution of G
call G A…call G with extra arguments appended; cuts inside are local
phrase NT Lrun DCG non-terminal NT on L with an empty remainder

is_str X, is_char X, is_atom X, is_list Xstring; character; atom; proper list

GoalMeaning
