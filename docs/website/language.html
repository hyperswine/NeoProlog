Language

Infera reads like Prolog with a lighter syntax: no parentheses around arguments, <- for rules, # comments, and inline queries that run when a file loads.

Files and items #

A file is a sequence of items, each ended by a period:

# comment
color red.                                  # fact
append [H | T] L [H | R] <- append T L R.   # rule
greeting -> [hello], name.                  # DCG rule
mypred : semidet (int: <=) (str: =>).       # declaration
<- import "mymod#3f2a...".                  # directive
> append X Y [1, 2]?                        # inline query (runs on load)

Predicates are identified by name and arity: maplist/2 and maplist/3 are different predicates. Calling a predicate that does not exist is an error, not a failure.

Operators #

From tightest to loosest binding:

OperatorsMeaning
^power (right-associative)
* / %multiply, integer/float divide, modulo
+ -add, subtract
::list cons (right-associative)
..range, used with in
< > <= >= #< #> #<= #>=numeric comparison; CLP(Z) comparison
= == != #= #!= is inunify, structural equality, disequality, CLP(Z) equality/disequality, arithmetic evaluation, domain
, -> ;conjunction, if-then, disjunction (inside bodies and parentheses)

Ground arithmetic in call arguments is evaluated before head matching, so fact (N - 1) R calls fact 4 R when N is 5. Arithmetic left in answers is evaluated when printed.

Clause bodies and control #

sign N S <- (N > 0 -> S = pos ; N < 0 -> S = neg ; S = zero).
first X <- member X [a, b, c], !.
safe X <- not (dangerous X).
count L N <- findall X (item X L) Xs, length Xs N.
  • A , B conjunction; A ; B disjunction; (C -> T ; E) if-then-else (the condition is committed to its first solution); (C -> T) without an else fails when C fails.
  • ! cut: commits to the current clause and to the choices made before it. It is transparent through , ; -> and local inside call, not, once, findall and forall.
  • not G negation as failure, once G, forall C A, findall T G L, call G Args….

DCG rules #

Head -> Body. defines a grammar rule; two list arguments are appended. Terminals are lists or strings (as character lists), { Goal } embeds an ordinary goal, and , ; -> ! work as in bodies. Run a grammar with phrase NT List or call the translated predicate directly.

greeting -> [hello], name.
name -> [world].
name -> [infera].
digits [D | Ds] -> [D], {{ D >= '0', D <= '9' }}, digits Ds.
digits [] -> [].

> phrase greeting [hello, world]?
true.
> greeting L []?
L = [hello, world]
L = [hello, infera]

Comments #

# starts a line comment, except when immediately followed by one of = ! < >, which makes it a CLP(Z) operator (#=, #!=, #<, #>, #<=, #>=). Put a space after # in comments that start with those characters.
