Engine

Resolution with per-argument indexing, tabling by default, cut through barrier markers, and output collected per answer.

Indexing #

Every argument position of every predicate is indexed on its principal functor (atom, number, string, character, or functor/arity). A call only tries clauses compatible with each of its bound arguments, so step (cpu 3 …) S or instr 2 I touch only matching clauses. Indexing never changes answers. Turn it off with name : noindex. or globally with <- noindex..

Tabling #

A tabled call is evaluated to a fixpoint: its answers are collected in a table keyed by the call variant, recursive variant calls consume the table instead of recursing, and the evaluation repeats until no new answers appear. Left recursion terminates and repeated calls are memoised.

Eligible positive rules with one recursive call first in the body consume only newly discovered answer batches. This avoids repeating old derivations. Mutual or nonlinear recursion, different recursive variants, declared contracts, control constructs, effects and constrained calls retain the general evaluator. Errors or resource exhaustion encountered by the fast path also fall back to that evaluator.

path X Y <- path X Z, edge Z Y.
path X Y <- edge X Y.

fib 0 0.
fib 1 1.
fib N F <- N > 1, N1 is N - 1, N2 is N - 2, fib N1 F1, fib N2 F2, F is F1 + F2.

> path a X?
X = b
X = c
> fib 50 F?
F = 12586269025

Tabling is on by default for predicates that are

  • recursive (they can reach themselves through calls),
  • pure (no write/nl, directly or transitively), and
  • not merely structurally recursive: predicates whose every self-call recurses on a proper subterm of a head argument (list and tree walkers such as length or append) always terminate and would only pay for their tables.

Control it with name : table … / name : notable. per predicate, or <- table. / <- notable. as the file default.

A tabled call collects all its answers before continuing, so a predicate with infinitely many answers (a generator like nat) must be declared notable. Otherwise the fixpoint stops after a bound and the answer reports "Search depth limit reached". Calls whose arguments carry CLP(Z) constraints, and answers that would carry constraints, are evaluated without tabling.

Cut and commitment #

Cut is implemented with barrier markers in the lazy answer stream: ! emits a marker for its clause's activation, alternatives stop when they see it, and the activation that owns the barrier consumes it. Declared det/semidet predicates, and predicates inferred semidet with their switch arguments ground, are committed to their first solution.

Effects and output #

Predicates are pure unless declared unsafe. Output builtins, file reads, assert/retract and cut are effects: a clause of a predicate without the flag that uses one, or that calls an unsafe predicate, is an unsafe-call error at load time. Inline queries are the entry points and may do anything. The intended style is to describe text with DCGs (seq, wr, fmt, padl…) and print it with emit from a query; see effects and DCG helpers.

write, writeln, print, nl and emit append to an output log carried with the solver state, so each answer prints exactly the output of the branch that produced it, in order. Tabled predicates replay the output recorded with their answers; predicates that produce output or read dynamic facts are never tabled automatically.

Limits and errors #

  • Resolution depth is bounded (100 000 nested activations). When a branch hits it the answer says so instead of looping forever.
  • Errors are per branch: an error in one branch is reported alongside the answers of the others ("Some branches raised an error").
  • Arithmetic on unbound variables, division by zero, unknown predicates, mode/sort/determinism violations and CLP(Z) type errors are all reported with the offending term.
